## 环境问题排查（重要结论）
.NET 10 SDK NuGet restore 崩溃（`Value cannot be null. (Parameter 'path1')`），两层根因：
1. **主因**：WorkBuddy 的 MSYS bash 环境缺失 `APPDATA`/`ProgramFiles(x86)` 等 Windows 标准环境变量 → .NET 10 `GetFolderPath` 返回 null → NuGet `XPlatMachineWideSetting` 崩溃。**在 WorkBuddy bash 里构建 dotnet 项目必须带环境变量前缀（见 MEMORY.md 的构建命令）**
2. **次因**：注册表 `HKLM\...\Explorer\FolderDescriptions` 缺失 3 个键（疑似被系统清理工具误删），已通过 .reg 导入修复：{7C5A40EF}ProgramFilesX86、{3EB685DB}RoamAppData、{5E6C858F}ProgramFilesCommonX86。备份在桌面 FolderDescriptions-backup-20260909-102745.reg

## Avalonia 11.3 API 注意点
- `WindowStartupPosition` 已改名 `WindowStartupLocation`（枚举成员不变：CenterScreen/CenterOwner/Manual）
- DatePicker/TimePicker 无 Header 属性（UWP 才有），需外置 TextBlock 标签
- ImmutableSolidColorBrush 在 Avalonia.Media.Immutable 命名空间
- StackPanel 无 FontSize/Foreground 属性（要设在子 TextBlock 上）
- .NET 10 SDK 默认生成 .slnx（非 .sln）新格式解决方案
